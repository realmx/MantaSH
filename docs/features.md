# 功能与范围

本页列出当前原生客户端的功能与入口。操作细节见[用户手册](user-guide.md)，实际运行证据与平台限制见[验收记录](acceptance.md)。

## 平台范围

| 平台 | 产物与能力 | 验证边界 |
|---|---|---|
| macOS arm64 / x64 | DMG；本地终端、SSH/SFTP 和全部工作台功能 | 已有 macOS 自动化与部分人工记录；不代表两个架构、所有系统版本均已实机验收 |
| Windows x86 / x64 / ARM64 | Inno Setup 安装器；ConPTY、本地 Shell 选择、SSH/SFTP 和原生窗口控制 | 安装、运行、DPI、输入法及 ConPTY 尚未实机验收 |
| Linux SSH 服务器 | 远端 Shell、SFTP，以及 Linux 资源、进程和端口采样 | 受服务器工具、权限和文件系统限制；不发布 Linux 桌面包 |

安装包及签名状态见[安装说明](user-guide.md#安装与首次打开)；平台检查入口见 [macOS](macos.md) 和 [Windows](windows.md)。

## 产品限制

- SSH 仅密码认证，不提供密钥认证、私钥路径或私钥口令。默认算法之外追加 `ssh-rsa`、`diffie-hellman-group14-sha1` 和 `hmac-sha1` 兼容配置；主机指纹仍须验证，真实旧版服务器尚待专项连接验收。
- SSH 不分屏；本地历史会记录，但当前本地页面没有历史弹窗或编码切换入口。
- 没有目录上传入口、跨会话远程粘贴或自动断点续传。重新传输创建新任务，从头传输。
- 编辑器不提供语言专用代码格式化、版本合并或重启后的草稿恢复；保存可能覆盖此前的外部修改。
- 不提供串口、云同步、插件市场、多层工作区或 JSON 连接库。

## 数据与隐私

连接资料、偏好、工作区和历史存于本地 SQLite；凭据存于独立加密库，不设主密码、不调用系统钥匙串。关闭密码记忆保留已有密码；CSV 导出包含解密后的明文密码。历史只接收可靠 Shell 命令事件，不记录原始键盘输入，但命令中的敏感参数仍可能被收录。备份、迁移、编码和文件完整性规则见[数据文档](data.md)。
