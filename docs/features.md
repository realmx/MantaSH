# 功能与范围

本文是面向使用者的快速功能清单。具体操作步骤见[用户手册](user-guide.md)，当前实现和验收证据见[交付状态](delivery-status.md)与[验收记录](acceptance.md)。

## 平台矩阵

| 能力 | macOS | Windows |
|---|---|---|
| MantaSH 桌面客户端 | 发布 arm64/x64 包 | 发布 x86/x64/ARM64 包 |
| 本地终端 | 已接入 | 已接入，实机未验证 |
| SSH/SFTP 客户端 | 已接入 | 已接入，实机未验证 |
| Linux 服务器监控 | 连接 Linux SSH 后可用 | 连接 Linux SSH 后可用，实机未验证 |

Linux SSH 服务器是系统信息的远端采样目标。

## 功能清单

### 本地工作

- 真实 PTY Shell、多标签、标签栏内排序和窗口状态恢复。
- 仅本地终端支持最多 5 个窗格，可左右、上下和混合分屏。
- Shell 命令历史集成、命令光标定位、输入法和终端程序鼠标报告。
- 中英文、白天/黑夜、界面与终端字体、12–18px 字号。

### SSH 工作

- 连接资料使用名称、主机、端口、用户和密码五项 CSV 格式。
- 主机指纹首次确认和变化提醒；密码认证成功后本机加密记忆。
- 连接库支持搜索、导入、导出、克隆、编辑、排序、多选和批量删除。
- 同一连接可以打开多个独立标签；断开后可在原标签重连并保留旧输出。

### 文件和编辑

- SSH 会话下方的 SFTP 文件面板，路径栏、目录树、列表和位置指示条。
- 单击单选、Shift 连续选择、Cmd/Ctrl 增减选择；双击文件夹进入，双击文本打开编辑。
- 上传本地文件、下载远端文件或目录，以及重命名、复制、粘贴、新建目录、删除和传输历史。
- 在线编辑支持严格编码、8 MiB 普通文本上限和失败草稿保留；重新打开读取远端最新内容，保存采用最后保存覆盖，可能覆盖较早的外部修改。

### 历史和系统

- 本地历史独立保存；全部 SSH 标签共享同一份命令历史。
- 历史支持搜索、复制、填入当前终端、明确执行和按 UUID 删除。
- Linux SSH 服务器提供 CPU、内存/Swap、磁盘、网络、进程和端口概览。
- 进程详情支持身份复核、普通结束和强制结束确认；端口支持筛选、排序、复制和关联进程查看。

## 明确不包含

- 串口、云同步、插件市场和多层工作区。
- SSH 会话分屏；分屏只属于本地终端。
- 密钥认证、私钥路径和私钥口令；连接库固定使用密码认证。
- Windows 实机验收结论；验收状态见[验收记录](acceptance.md)。
- 目录上传的可见入口和传输失败后的自动续传；重新传输会创建新任务并从头开始。

## 数据边界

连接资料保存在 MantaSH 数据目录，密码单独进入本机 AES-256-GCM 加密库。连接导出 CSV 含解密后的密码列，必须按敏感文件处理。完整数据和安全说明见[数据文档](data.md)。
