# 折流

形状由一条有方向的路径展开，经过两次折返形成稳定的节奏。主形应在远看时成为完整轮廓，近看时显露转折与空隙的关系。以精确的边缘和连续的负空间表达秩序，不依赖附加图案解释含义。

几何需要经过光学修正。相同的角度不一定产生相同的视觉重量，因此谷底、转角和外缘分别校准；小尺寸优先保留轮廓与开口，大尺寸才展示细节。每一道切口都应有明确作用，呈现耐心打磨后的清晰度。

颜色保持深浅之间的直接关系：深蓝承托明亮的主形，一处浅蓝标记引导视线停驻。去掉颜色后，形状仍应完整成立。精细来自比例、间隔和边缘控制，而非材质效果的堆积。

文字沿用低声量的排布。字标与图形各自拥有空间，彼此通过基线和重量呼应；说明文字只提供识别所需的信息。整幅画面应像经过反复校准的器物，简洁、稳定，并允许视线自然流过。

本项目将这一方向落实为“共享透镜”的抽象构成：一实一空两个圆在深底上交叠，中央共享一枚透镜——本地与远端、终端与文件面板，一次连接被看见。品牌图形不改变已确认的工作台布局与用户字体设置。
