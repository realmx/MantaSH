# 用户手册

本手册按实际操作组织。快速查看支持范围可用[功能导航](features.md)，故障处理见[排障](troubleshooting.md)，数据备份与格式见[数据文档](data.md)。

## 安装与首次打开

从 [GitHub Releases](https://github.com/realmx/MantaSH/releases) 下载对应架构的安装包，并核对同名 `.sha256`。macOS 提供 Apple Silicon / Intel DMG，Windows 提供 x86 / x64 / ARM64 Inno Setup 安装器。macOS 也可使用 Homebrew：

```sh
brew install realmx/taps/mantash --cask
brew upgrade --cask mantash
```

macOS 打开 DMG 后将 `MantaSH.app` 拖入“应用程序”，再推出映像；Windows 运行安装器，按提示完成安装。macOS 包使用 ad-hoc 签名、未经 Apple 公证；Windows 安装器未签名，可能触发 SmartScreen。Windows 安装和运行仍待实机验收，详见[平台说明](windows.md)。当前运行版本在“关于 MantaSH”中查看，发布版本以 Release 页为准。

### macOS 无法直接打开

首次启动可能被 Gatekeeper 拦截。先核对下载来源与校验和；校验失败或系统提示应用已损坏时重新下载。

1. 确认应用已放入 `/Applications`，然后在 Finder 中尝试打开并关闭拦截提示。
2. 打开苹果菜单 →“系统设置”→“隐私与安全性”，在安全性区域点击 MantaSH 旁的“仍要打开”。
3. 用登录密码或触控 ID 确认，再点击“打开”。

“仍要打开”只在尝试启动后短时间出现，找不到时重新尝试打开。组织管理的 Mac 可能禁止放行，应联系管理员；不要通过命令关闭安全检查。

## 工作台与常用入口

首次启动打开本地 Shell。顶栏加号新建本地标签，“连接”打开连接库，齿轮打开设置。顶部只保留应用图标、可滚动标签和固定操作区。工具栏随当前会话变化：

| 区域 | 本地会话 | SSH 会话 |
|---|---|---|
| 终端 | 全宽；可分屏 | 上方终端；不能分屏 |
| 文件 | 无远程文件面板 | 下方 SFTP 面板；工具栏文件入口可开关 |
| 历史 | 自动记录本地命令，当前无弹窗入口 | 工具栏历史入口打开全部 SSH 标签共享的列表 |
| 系统 | 无远端概览 | 右侧 Linux 概览；工具栏系统入口可开关 |
| 编码 | 使用会话编码，无可见切换入口 | 地址旁的会话编码入口 |

在线编辑、历史、连接库、设置和系统详情使用弹窗。X/Esc 依据当前内容关闭、取消或收起；有列表选择时，Esc 可先清空选择。普通子弹窗返回时保留父弹窗的搜索、选择、滚动和焦点；危险确认始终针对打开确认时的目标。

## 本地终端

### Shell 与输入

macOS 默认使用系统 `$SHELL`；Windows 自动发现 PowerShell 7、系统 PowerShell、CMD、Git Bash 等可用 Shell。可在设置的“本地终端 Shell（新会话生效）”中选择，当前项有勾选；更改只影响之后新建的本地会话，已有 Shell 不重启。初始目录为用户主目录；已选 Shell 不可用会报错，不静默替换。

Tab/Shift+Tab 交给 Shell 或前台程序补全，Ctrl+C、Ctrl+D 保留终端含义；表单里的 Tab 才切换控件。输入法组合期间保护尚未提交的文本。窗口尺寸或字体变化会同步调整终端网格和 PTY。

### 选区、粘贴与鼠标

拖动选择文本，双击选词；向上或向下拖选都会包含起点和终点所在的字符（含行首第一列）；拖选时指针停在终端上/下边缘或移出边缘，会按方向持续滚动回滚历史并延伸选区，越过边缘越远滚得越快，松开鼠标、指针回到终端内或到达历史顶部/最新输出时停止。已有选区时按住 Shift 单击，会保留原选区的起点（最初按下鼠标或双击的位置，而不是离点击处较近的一端），把终点改到点击处，点击位置在选区之前或之后、同行或跨行都会连续选中并包含两端字符；继续按住拖动可接着调整终点并支持边缘自动滚动；双击选词得到的选区延伸时仍按整词扩展。没有选区（或只有单击留下的空点）时 Shift+单击照常开始新选区。Shift+单击不发送鼠标报告、不移动 Shell 光标；不按 Shift 的单击仍清除并重新开始选区。右键在存在选区时复制，否则粘贴。复制、粘贴、全选快捷键见[快捷键](#快捷键)。粘贴遵循前台程序请求的 bracketed-paste 模式。

前台程序启用鼠标报告时，点击和滚动可交给程序；按 Shift 使用本地选区或回滚，也可在设置关闭鼠标报告。触控板慢速滚动会累计细小位移。可靠识别的 Bash/Zsh 提示符支持点击已输入命令来移动真实 Shell 光标；前台程序、密码提示和无法识别的提示符不自动定位。

普通 `vim`、`nvim` 和 GNU `nano` 的新会话提供鼠标适配，已有 alias/function 优先；macOS 自带 `/usr/bin/nano`（Pico）另作兼容处理。Windows 输入法和鼠标定位仍需实机确认。

### 回滚与清屏

只有实际存在滚动历史时才显示滚动条。普通屏幕擦除保留真实溢出的历史；完整清屏/清历史后，缩放不会恢复已清除的旧提示符。Vite 一类程序用空行和回顶擦除刷新时，可容纳的真实输出会回填空白区域，不单因刷新留白出现额外滚动条；超出可视区的输出仍能回滚。

## 标签与本地分屏

标签在当前标签栏内左右拖动排序；栏外释放、Esc 或窗口失焦会取消。鼠标滚轮或触控板横滑浏览较多标签。标签名称随可靠的目录/程序报告更新，SSH 显示连接名或地址；悬停查看完整信息。关闭按钮独立响应。

每个本地标签最多 10 个窗格，支持左右、上下和混合布局。先聚焦目标窗格，再使用分屏按钮或快捷键；新窗格获得焦点。拖动分隔线调整比例，聚焦分隔线后也可用方向键调整。Ctrl+Tab 切换本地窗格。关闭窗格只结束该窗格，布局自动收拢；关闭最后一个标签后保留空工作台和新建入口。

SSH 标签没有分屏入口。关闭标签或窗口时，未保存文件和相关活动传输会触发保护确认，详见[工作区恢复](#窗口与工作区恢复)。

## SSH 连接

新建 SSH 可用 macOS `Cmd+N` / Windows `Ctrl+Shift+N`，也可从连接库点击添加。填写名称、主机、端口、用户名和密码：名称可留空后按地址命名；新资料默认用户名 `root`、端口 `22`，均可修改。编辑或克隆资料保留原用户名和端口，设置中没有全局端口选项。

“仅保存”保存资料，不保存未经认证的新密码；“保存并连接”保存资料并开始建连。当前使用密码认证，不提供密钥认证。首次连接或指纹变化时必须经可信渠道核对主机身份；变化提示同时显示旧值和新值。身份确认完成后，程序才读取和发送凭据。客户端在默认算法之外追加 `ssh-rsa` 主机密钥、`diffie-hellman-group14-sha1` 和 `hmac-sha1` 兼容配置；真实旧版服务器的连接仍待专项验收。

建连、包含身份确认的握手、单次认证分别有 15、90、20 秒上限。超时或取消后可重新连接；后台标签的身份/密码提示需切回该标签处理。密码被拒绝时等待手动更正，不自动反复尝试。

工具栏左侧闪电按钮同时表示状态和操作：

| 颜色 | 当前状态 | 点击动作 |
|---|---|---|
| 绿色 | 已连接 | 断开连接 |
| 蓝色 | 正在连接、确认身份或认证 | 取消 |
| 红色 | 已断开、失败、取消或等待重连 | 重新连接 |

悬停显示动作名称。原标签重连会把当前画面推入滚动历史并在新连接成功后继续保留，失败或取消仍显示原终端；断线后文件和系统面板关闭。SFTP 通道故障可单独重试，不必关闭仍可用的 SSH 终端。

### 凭据记忆

“记住认证凭据”默认开启，每次连接尝试开始时固定本次策略：开启时，身份确认后读取已保存密码，新密码认证成功后写入本机 AES-256-GCM 凭据库；关闭时不读取、不写入，已有密码保留。切换设置影响下一次连接尝试。

新建、编辑、克隆和重连表单的密码框右侧有眼睛按钮，可显示或隐藏当前输入的密码；每次打开表单都默认隐藏，关闭即复位。编辑表单打开时不回填密码；在编辑已有连接、密码框为空且启用记忆时，点击眼睛会读取并显示已保存密码（没有保存值时提示“未保存密码”），再次点击重新隐藏。显示出的密码未修改时保存或连接不算新密码，不会重写凭据；修改后按新密码规则处理。关闭记忆时眼睛按钮只切换已输入内容的显示，不读取已保存密码；在启用记忆时，空密码可复用已有凭据。认证错误不覆盖旧密码，保存失败不切断已连接终端。没有主密码，也不调用系统钥匙串。克隆资料不复制密码。CSV 导入密码属于单独的明确确认路径，规则见下一节及[凭据文档](data.md#凭据)。

## 连接库

点击“连接”，或按 macOS `Cmd+Shift+O` / Windows `Ctrl+Shift+O`。搜索匹配名称、主机、用户名和端口；↑/↓ 选行，Enter 连接。每行右侧提供编辑、克隆和连接。连接动作始终新开标签，同一资料可打开多个独立会话。

单击单选，Shift 连选，Cmd/Ctrl+单击增减选择；Esc 先清空选区，再关闭。顶部支持按名称排序，也可拖动行调整顺序，最终顺序会保存。选中后可批量删除，确认只包含当前可见选中资料；搜索隐藏项不会成为删除目标。编辑、克隆或删除资料不将已经打开的会话替换为其它连接。

## 连接 CSV

连接库顶部导入、底部导出使用五列 CSV：`name,host,port,username,password`。文件须为 UTF-8，可带 BOM，大小不超过 8 MB；表头规则与转义见[格式说明](data.md#连接-csv)。

导入先预览新增、重复与错误行，可移除不需要的行。名称、主机、端口、用户名均一致时算重复，主机忽略大小写；默认跳过重复，明确开启更新后才更新已有资料。错误行不影响其它合法行；非法表头会拒绝整个文件。

确认后先保存资料，再按连接 UUID 写入有效密码。此操作不代表服务器已认证该密码，也不受下一次 SSH 连接的记忆策略代替。空密码不删除旧值，密码首尾空白原样保留；部分密码写入失败可单独重试，不重复导入资料。

导出始终包含整个连接库，不受当前搜索或选区限制。系统保存面板生成 `mantash-connections.csv`，首次默认下载目录，成功后记住所选目录。**密码列为解密后的明文，须按敏感文件保存和传递。** 未保存的密码列为空；密码读取失败会中止导出，避免生成不完整文件。

## 远程文件

连接成功后按设置打开文件面板；也可从 SSH 工具栏打开。目录树、路径栏和文件列表用于导航：点击树节点或双击目录进入，路径栏输入目录后按 Enter，失败保留原位置。上级、刷新、隐藏文件和新建目录入口位于面板。Shell 可靠报告目录变化时，文件栏自动同步；当前没有单独的手动同步入口。

文件列表为名称、大小、修改时间、操作四列，没有复选框。修改时间取自服务器列目录时返回的 mtime，按本机时区显示为 `YYYY-MM-DD HH:mm:ss`（精确到秒，目录同样显示）；服务器未提供时显示“—”。默认按目录在前、名称排序；点击“大小”或“修改时间”表头依次切换为降序（最大/最新在前）、升序和默认顺序，当前排序的表头显示箭头。任何排序下目录都排在文件之前，组内按所选列排序、相同值再按名称；目录没有大小，按大小排序时保持名称顺序；服务器未提供的大小或时间在两个方向都排在最后。排序只保存在当前文件面板内，刷新和进入其它目录时保留，重启后恢复默认；已选中的项目在重新排序后保持选中，Shift 连选和方向键按新的显示顺序计算。单击单选，Shift 连选，Cmd/Ctrl 增减选择；↑/↓、Shift+方向键、全选和 Enter 可操作当前列表。行内“预览”（Lucide `eye`）以只读方式打开单文件，不改变当前选区；右键菜单提供“预览”和“编辑”。双击在可安全按严格编码打开时进入编辑，否则对文本类文件尝试回退解码后只读预览，仍无法识别则报错。大于 8 MB 的文件不能在应用内打开，需下载。导航或刷新重置选区，隐藏项和过期请求不能成为批量目标。

行内直接提供重命名、复制、移动、下载和删除；点击动作不改变选区。重命名不能使用无效名称或覆盖已有目标；关联草稿路径在成功后更新。复制后可在同一会话、同次连接内导航再粘贴，重连/关闭后失效，不跨会话粘贴。同名冲突会提示，不默认覆盖。复制依赖服务器 POSIX `cp` 支持与权限。

移动与复制用法相同：点击行内“移动”（剪刀图标）或在右键菜单对选区选择“移动”，标记后该行移动按钮保持选中，工具栏显示“移动到此处 (N)”和取消按钮；导航到目标目录后点击“移动到此处”（或右键“移动到此处”），通过 SFTP 重命名完成，不复制数据。目标为原目录、把文件夹移到自身或其子目录、标记项重名或目标已有同名条目（含隐藏文件）时直接提示并保持原样，不覆盖；被拒绝时待移动内容保留，可换目录重试，也可随时点击取消。成功后刷新目录、选中移入的条目、清除待移动内容，已打开草稿的路径随之更新。批量移动中个别条目失败时逐项报告，已移动的条目不回滚。跨文件系统的移动取决于服务器是否支持重命名，不支持时报告失败、不改为复制再删除。与复制共用一个待粘贴缓冲：标记移动会替换复制，反之亦然；重连/关闭后失效，不跨会话移动。

批量下载/删除只处理当前可见选中项。删除须核对完整路径，不通过回收站恢复；目录处理不递归跟随符号链接，设备等特殊文件受限制。操作失败显示具体原因，过期选择器回复不会把操作施加到新目录。

## 上传下载与传输记录

上传使用文件面板的上传入口选择本地普通文件；下载使用行内下载或选中项下载，支持远端文件和目录。没有目录上传入口。系统选择器返回后先进入核对页，可移除单项；每项显示方向、文件名和可信大小。“覆盖已有普通文件”默认关闭。

点击开始后，全应用最多两个传输任务并发，跨会话、跨批次共用此上限，其余排队。运行页和记录的悬停提示提供完整源/目标路径、状态及错误。已知总量显示进度环和百分比，未知总量显示活动指示及已传字节，不推算虚假进度。

X/Esc 或“后台继续”只收起运行视图，任务继续。要停止本批任务，选择“停止未完成”并确认；已完成项保留。取消或失败后可“重新传输”，重新核对并创建新任务，从头传输，不自动续传或默认覆盖。

“传输记录”显示当前会话任务，可取消活动任务、重新传输失败/取消项、定位成功下载文件、移除已结束记录。有选中项时仅移除所选，无选中项时移除本会话全部已结束记录，不再二次确认；移除记录不删除已传文件。重启时未完成任务变为中断。Windows 不支持的目标文件名会使落盘失败，但不影响远端浏览。

## 在线编辑

不超过 8 MB 的普通文件可在应用内打开。**编辑**（双击可安全文本、右键“编辑”）进入可保存的编辑器；**预览**（行内眼睛按钮、右键“预览”，或双击仅能靠回退解码打开时）进入只读预览：正文不可改、不提供保存与会改写文本的格式化；预览工具栏在解码可安全保存时提供“编辑”切换到编辑模式。二进制、设备文件会被拒绝。符号链接仍先确认真实目标，确认后沿用原打开意图（预览或编辑）。

没有未保存草稿时重新读取远端内容；若该路径已有脏编辑草稿，预览与编辑入口都回到该草稿（避免与远端预览冲突）。工具栏显示路径、保存编码；编辑模式另有基础格式化，正文支持真实行号、文本选择、撤销/重做和滚动。基础格式化统一 CRLF/CR 为 LF、清理行末空格/Tab、补缺失末尾换行，保留缩进、Unicode、空行及已有多个尾换行；它是一次可撤销编辑，不自动保存，也不做语言专用代码格式化。

点击保存或使用保存快捷键写入远端。无法用所选编码表示的字符会阻止保存；失败保留草稿。保存过程中继续输入的内容仍标为未保存。保存采用最后保存覆盖，可能覆盖外部程序较早写入的内容，不自动合并版本。

X/Esc 只收起编辑器，草稿驻留本次会话；“放弃”需另行确认。关闭标签/窗口或安装更新前可选择保存、放弃或继续编辑。重连后旧草稿不会自动交给新连接保存，重启后不恢复草稿；先保留需要的内容再核对远端目标。

保存替换失败时可能留下 `.mantash-recovery-<uuid>` 文件。先根据错误路径核对原文件和恢复文件，不要批量清理。具体文件完整性和权限边界见[数据文档](data.md#编码在线保存与文件权限)。

### 终端与文件编码

SSH 工具栏的会话编码入口支持 UTF-8、GBK、GB18030 和 Big5；切换不清空既有网格，选择随工作区保存，不写入连接资料。本地终端当前没有编码切换入口。

文件读取使用 Auto：识别 UTF-8 / UTF-16 LE/BE BOM，否则严格按 UTF-8。常见文本/日志/配置扩展名与名称（如 `.log` `.conf` `.txt`、`Dockerfile`、`Makefile`、`*.conf.*` 等）在 UTF-8 失败时会再尝试 GBK/GB18030；仍失败且为预览意图时可用带替换字符的回退解码，并强制只读、禁止保存。解码允许 ANSI 日志中的 ESC 等无害控制字符，仍拒绝 NUL 与明显二进制。编辑器编码选项用于**保存**，支持 UTF-8、GBK、GB18030、Big5、UTF-16 LE/BE；保存始终严格编码，不含替换字符。非允许列表且无 BOM 的非 UTF-8 文件可先下载，用外部工具转码。

## 命令历史

SSH 工具栏历史入口或 macOS `Cmd+2` / Windows `Ctrl+Shift+2` 打开共享 SSH 历史。本地命令单独记录，当前本地页面没有历史入口。

记录只含命令和内部 UUID，不显示来源或时间。首尾空白去除后按完整文本精确去重；同列表再次可靠执行会沿用记录并置顶，本地和 SSH 列表独立，两者总计最多 5,000 条。搜索只匹配命令；复制或填入不改变排序。

行内提供复制、填入和执行。填入不发送回车，明确执行才提交；前台程序、密码提示或断线时只允许复制。动作固定指向打开历史时的终端，切到其它标签/窗格后不能继续提交，重连后需重新打开。支持单选、Shift/Cmd/Ctrl 多选、确认删除；隐藏项不参与删除，Esc 先清选区再关闭。

只记录 Shell 主动报告的命令，不抓取按键或密码输入。当前接入 Zsh、Bash 和 PowerShell/PSReadLine；自定义钩子、空格前缀或 Shell 隐私规则可能阻止收录，不读取 Shell 历史文件。主动写在命令中的敏感参数仍可能进入历史。

## Linux 系统信息

SSH 连接 Linux 主机后，右侧概览显示 CPU、内存/Swap、磁盘和网络。可见期间约每 3 秒采样；CPU 与网络速率需要两次有效采样。断线清空监控，切换会话后的迟到结果不会更新当前主机。工具缺失、权限不足、失败、过期与真实零值分别处理。

CPU 卡打开总体与每核详情；磁盘卡打开全部挂载点、设备、文件系统及容量详情；内存/Swap 卡打开进程；网络卡显示收发速度、短期趋势和接口累计量，并打开端口。趋势最多约 180 秒，采样间隔过长时断线，不补造数据。

### 进程与结束操作

进程列表列出 PID、命令、用户、CPU、内存。点击表头排序；搜索仅匹配“命令”列的可执行程序及参数，不额外匹配 PID/用户名。长命令可悬停查看全文，行末箭头打开详情。

详情平铺 PID、状态、CPU、常驻内存、用户、父 PID、启动时间、完整命令和补充状态；PID 与完整命令可复制。后台更新保留文本与滚动，CPU 可因多核超过 100%。详情有效时约每 3 秒请求新样本，不需手动刷新。

“结束”发送 SIGTERM，“强制结束”发送 SIGKILL，均需确认主机、PID 和进程身份。应用复核连接、请求、PID、启动标识和主机启动标识；受保护目标、断线、身份变化或过期采样会禁用操作。**发送信号不等于进程已退出**：最多等待 10 秒的有效采样确认，不自动升级信号或重试。权限和服务器策略可能拒绝操作。

### 端口

端口列表支持关键词搜索、全部/TCP/UDP 筛选、按端口数值或协议排序。展开行可查看服务器返回的完整本地端点、对端、协议/状态与进程信息，保留 IPv4/IPv6 原文和重复记录。

可复制端点或数字端口；关联 PID 存在于当前进程样本时，可进入进程详情。查看和复制不会关闭端口。采样依赖服务器 `ss`，可见进程信息受权限限制；失败、空结果和断线分别提示。

## 设置

顶栏齿轮或 macOS `Cmd+,` / Windows `Ctrl+Shift+,` 打开设置。外观、终端、连接与安全三组之间以分隔线区分，主题和语言的当前项为蓝色选中态。

| 设置 | 默认或范围 | 生效时机 |
|---|---|---|
| 语言 | 中文 / English | 立即更新界面 |
| 主题 | 白天 / 黑夜，默认白天 | 立即生效；手动选择会关闭系统跟随 |
| 跟随系统外观 | 默认关闭 | 开启后跟随系统深浅外观 |
| 界面字体、字号 | 系统字体；默认 14px，12–18px | 立即生效 |
| 终端字体、字号 | 平台等宽字体；默认 12px，12–18px | 立即生效并重算网格，已有会话不重建 |
| 本地终端 Shell | 平台发现的可用 Shell | 新建本地会话生效 |
| 鼠标报告 | 默认开启 | 立即影响终端输入处理 |
| 连接后打开文件面板 | 默认开启 | SSH 连接成功时应用 |
| 记住认证凭据 | 默认开启 | 下一次连接尝试生效；关闭不删除旧密码 |

四项布尔设置使用右对齐开关：蓝色且滑块在右表示开启，灰色且在左表示关闭。点击切换，也可 Tab/Shift+Tab 聚焦后按 Space 或 Enter；长按不连续切换。字体选择器列出本机已安装字体，可搜索后选择。

“恢复默认”还原可见设置，保留窗口、面板、目录、连接、历史和密码，不重启运行中的 Shell。设置自动异步保存，无需另点应用。底栏右侧版本按钮打开关于。

## 窗口与工作区恢复

标签外空白标题栏用于系统拖窗；macOS 双击执行系统 Zoom，系统“窗口”菜单提供平铺、居中、填满、全屏与还原，`Cmd+Shift+0` 打开同一菜单，选项随系统版本变化。Windows 右侧保留原生最小化、最大化/还原、关闭，标题栏拖动和双击由系统处理；最大化与全屏不同，应用内窗口尺寸/全屏入口按平台提供。

SSH 右栏可拖动调宽；聚焦分隔线后方向键每次 8px，Shift+方向键每次 32px，Home/End 到边界，双击恢复默认 280px；显示上限为客户区宽度的 50%。文件面板与本地分屏分隔线可调整各自比例。

连接资料、偏好、标签顺序、活动窗格、布局、正常窗口尺寸及面板偏好自动保存。重启后本地会话启动新 Shell，SSH 等待手动重连；不恢复正在运行的程序、编辑草稿或活动传输，未完成传输记录标为中断。

关闭标签/窗口与安装更新前检查未保存文件和活动传输，按确认结果保存、放弃或取消关闭；正常退出等待最后的元数据保存。数据库异常时保留原文件并提示仅本次运行模式，不清空旧数据。备份须正常退出后复制数据，凭据库与 key 要一起保存，见[数据与恢复](data.md)。

## 关于与更新

设置底栏的版本按钮打开“关于 MantaSH”；macOS 应用菜单也有关于入口。弹窗显示品牌、当前运行版本和项目链接，底栏“检查更新”立即检查，显示进度、新版本、无适用更新或错误，失败可重试，关闭返回关于。

自动检查在普通启动约 3 秒后进行，之后每 24 小时检查，失败约 1 小时后重试。仅发现更高且适配当前平台的稳定版才询问，已有重要弹窗结束后再提示。确认更新才下载、校验 SHA-256 并准备安装；取消可停止本次流程，当前运行不再自动提示同一版本，手动检查仍可重新查看。

安装前保护草稿和传输、保存工作区并交给安装助手，随后退出、安装并重启。安装位置、权限、系统安全提示和日志规则见[自动更新](updates.md)；助手启动不代表安装成功，重启后须核对关于中的版本。
