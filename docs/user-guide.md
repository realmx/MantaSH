# 用户手册

## 安装与首次打开

从 [GitHub Releases](https://github.com/realmx/MantaSH/releases) 下载对应架构的 macOS DMG 或 Windows Inno Setup 安装器，并核对同名 `.sha256`。macOS 也可通过 Homebrew 安装、升级：

```sh
brew install realmx/taps/mantash --cask
brew upgrade --cask mantash
```

源码基准版本为 `1.1.10`；发布版本以 tag 和 Release 页为准，“关于 MantaSH”弹窗正文显示当前运行版本。macOS 包采用 ad-hoc 签名、未经 Apple 公证；Windows 安装器未签名，可能触发 SmartScreen。Windows 的运行和安装体验尚未实机验收。

应用自动检查最新稳定版本，仅发现更高版本时询问是否更新。点击“确定更新”后自动下载、校验并进入安装；取消则不更新。安装前仍会检查未保存文件和活动传输，完成后重启应用。检查频率、平台限制及验证方法见[自动更新](updates.md)。

在“关于 MantaSH”弹窗 footer 点击“检查更新”可立即手动检查，弹窗显示检查进度和结果：新版本、无适用更新或失败原因；失败可重试，关闭返回关于弹窗。此前取消过的版本也可手动重新检查，仍需确认后才下载和安装。

### macOS 无法直接打开

首次启动可能被 Gatekeeper 拦截。先核对下载来源与校验和；校验失败或系统提示应用已损坏时重新下载，不要绕过安全检查。

1. 打开 DMG，将 `MantaSH.app` 拖入“应用程序”（`/Applications`），推出磁盘映像。Homebrew 安装则直接在“应用程序”中找到应用。
2. 在 Finder 中尝试打开应用并关闭拦截提示。
3. 打开苹果菜单 →“系统设置”→“隐私与安全性”，在安全性区域点击 MantaSH 旁的“仍要打开”。
4. 按提示用登录密码或触控 ID 确认，再点击“打开”。

按钮只在尝试打开后短时间出现；找不到时重新尝试第 2 步。组织管理的 Mac 可能禁止放行，应联系管理员。不要用 `xattr` 等命令关闭系统级检查。

## 工作区与设置

首次启动打开本地 Shell。顶栏加号新建本地会话，“连接”打开 SSH 连接库；本地终端全宽显示，SSH 使用上方终端、下方文件面板和右侧系统概览。文件编辑、历史与详情在弹窗中打开，连接失败或断开时文件与系统面板关闭。

设置可切换中英文、界面和终端字体及字号（默认 14px/12px，范围均为 12–18px）；顶栏切换明暗主题。字体选择即时生效，“恢复默认”只还原设置中的语言和字体字号，不更改主题、窗口尺寸等其它偏好。普通子弹窗关闭后返回原弹窗，并保留搜索、选择和滚动状态；涉及删除、信任与未保存内容的确认仍按各自目标处理。

应用菜单首项“关于 MantaSH / About MantaSH”打开应用内关于弹窗，显示品牌、版本和项目链接，footer 提供“检查更新”，通过右上角关闭按钮或 Esc 关闭。设置 footer 右侧为“恢复默认”，不显示版本号。

## 本地终端

macOS 使用系统 `$SHELL`；Windows 可在设置中选择已发现的本地 Shell（PowerShell 7、系统 PowerShell、CMD、Bash 等），选择仅对新建本地会话生效，已有会话继续使用原 Shell。初始目录为用户主目录。Tab/Shift+Tab 交给终端程序或 Shell 补全；连接与设置表单中的 Tab 仍切换控件，输入法组合期间不提交补全键。Ctrl+C、Ctrl+D 保持 Shell 含义。

设置中点击“本地终端 Shell（新会话生效）”下一行的选择器可展开下拉菜单，点击目标 Shell 后保存；当前项显示勾选标记。点击选择器本身不会轮换 Shell，取消菜单不修改选择。

拖动选择文本、双击选词；右键在已有选区时复制，否则粘贴。终端程序启用鼠标报告时点击交给程序，按 Shift 可使用本地选区或回滚。触控板慢速滚动会累计，不丢弃不足一行的位移；粘贴遵循程序请求的 bracketed-paste 模式。

可靠识别的 Bash/Zsh 提示符支持点击已输入命令来移动真实 Shell 光标；运行中的程序、密码提示或无法可靠识别的提示符不会自动定位。普通 `vim`、`nvim` 和 GNU `nano` 的新会话启用鼠标适配，已有用户 alias/function 优先；macOS 自带 `/usr/bin/nano`（Pico）另作兼容处理。窗口缩放同步 PTY 和网格，`clear` 后不会因再次缩放恢复已清除的旧提示符。Windows 输入法与光标操作仍待实机确认。

本地终端仅在存在滚动历史时显示滚动条。Vite 等程序以连续换行填充后回顶擦除来刷新时，能够容纳的旧输出会回到空白可视区域，启动命令与新内容保留，不会只因刷新留白出现多余滚动条；实际内容超出可视行数时仍可正常回滚。普通清屏保留此前真实溢出的历史，因此已有历史且无法全部容纳时，即使当前画面较少仍会显示滚动条。

## SSH 连接与连接库

点击“连接”或按 macOS `Cmd+Shift+O` / Windows `Ctrl+Shift+O` 打开连接库。搜索可匹配名称、主机、用户和端口；↑/↓ 选行，Enter 连接。单击单选，Shift 连选，Cmd/Ctrl+单击增减；Esc 在有选中行时先清空选择，否则关闭弹窗。选中项可批量删除，必须核对确认内容；搜索后不可见的行不成为删除目标。拖动行可排序，克隆会产生新连接 UUID 且不复制已保存密码。

“添加”位于底栏；表单填写主机、端口、用户名和密码，名称可留空以地址命名，编码在连接后的 SSH 会话工具栏设置。“仅保存”只保存资料，不保存未经认证的新密码；“保存并连接”进入主机验证。同一资料可打开多个独立 SSH 标签，连接库的连接动作始终新开实例。

首次连接必须通过可信渠道核对主机指纹；指纹变化时比较旧值和新值，不要仅为消除提示而批准。表单可预先输入密码，但程序只在主机身份确认后读取和发送凭据。当前不支持密钥认证，也不支持仅提供 RSA 主机密钥的服务器。建连、含身份确认的握手和单次认证分别有 15、90、20 秒上限，超时或取消后重新连接会创建新尝试。

密码认证成功后自动写入本机 AES-256-GCM 凭据库，用于重连、新标签和重启后复用；没有主密码，不调用系统钥匙串。保存失败会提示，但不切断已认证的终端；错误密码不会覆盖旧值。编辑资料时后台读取已保存密码，用户新输入不会被迟到读取覆盖；密码被拒绝时等待手动更正，不自动重试。断线标签可在原标签重连，保留旧终端输出；连接库新开会话不复用旧标签。SFTP 故障不强制关闭可用的 SSH 终端。

## 连接 CSV

连接库导入、导出固定使用 `name,host,port,username,password` 五列 CSV；详见[数据格式](data.md#连接-csv)。导入先预览新增、重复与错误行，默认跳过重复，明确选择后才更新已有资料，错误行不会清空其它记录；确认导入的有效密码会按连接 UUID 尝试写入本机加密库，不等于已通过服务器认证。导出通过系统保存面板生成 `mantash-connections.csv`，首次默认定位下载目录，成功导出后记住所选目录；密码列是解密后的明文，务必按敏感文件保存和传递。

## 标签与分屏

顶部标签仅在标签栏内左右拖动排序，松开栏外或按 Esc 取消；滚轮和横向触控板滑动可浏览较多标签。标签外的空白标题栏用于拖动窗口，双击空白区执行系统 Zoom。标签名称随可靠的本地目录/程序变化；SSH 标签显示连接名或地址，悬停可看完整信息。

只有本地标签支持左右、上下及混合分屏，每个标签最多 5 个窗格。先聚焦目标窗格再点击标签栏右侧的分屏按钮；新窗格获得焦点，拖动分隔线或用方向键调整比例。SSH 标签没有分屏入口。关闭窗格不影响其它窗格；关闭标签/窗口时若有未保存文件或相关传输，会先请求确认。

## 远程文件与传输

SSH 文件面板包含目录树、路径栏、列表和文件操作。点击目录树或双击文件夹导航，双击普通文本打开编辑；输入远端目录路径后按 Enter，路径不存在则保留原位置。单击行单选，Shift 连续选择，Cmd/Ctrl 增减选择；键盘 ↑/↓、Shift+方向键、Enter 可操作当前列表。导航/刷新重置选区，隐藏项过滤后不能作为批量目标。

文件面板提供上传文件、下载文件或目录、重命名、复制/粘贴、新建目录和删除；当前没有目录上传的可见入口。批量下载和删除只处理当前可见的选中项，重命名要求单选，删除前核对完整路径。若在系统文件选择器打开后切换会话、目录或选区，旧选择结果会被忽略。

上传/下载先进入目标核对页，展示来源、目标和可信大小，可移除单项；“覆盖已有普通文件”默认关闭。提交后显示排队、进度和结果，每批最多两个任务并发：已知总量显示百分比，未知大小显示已传字节。关闭运行弹窗或选择“后台继续”不会停止任务；“停止未完成”需确认本批目标，已完成项保留。失败/取消显示原因，点击“重新传输”会创建新任务并重新核对，不自动覆盖或续传。

“传输记录”可查看、取消活动任务或移除已结束记录。进行中的上传/下载以环形图显示已知总量的进度，悬浮可查看方向和百分比；未知总量显示旋转指示器，悬浮可查看方向和已传字节。有选中项时只移除所选，无选中项时移除本会话全部已结束记录，不再二次确认；移除记录不删除已传文件。成功下载可点“定位文件”在本机查看目标；重启后的活动任务显示为中断。Windows 无法落盘的远端文件名会报错，不影响远程浏览。

## 在线编辑与编码

编辑器处理不超过 8 MB 的普通文本；二进制和设备文件会拒绝。符号链接需确认真实目标后才打开。再次打开同一路径会读取远端最新内容，不复用旧缓冲区；编辑弹窗的关闭按钮只收起视图，未保存草稿仍驻留本次会话，重连或重启不自动接管旧草稿。

保存编码可在编辑器中选择；无法表示的字符拒绝写入。读取时 Auto 识别 UTF-8/UTF-16 BOM，否则按 UTF-8。保存采用最后保存覆盖：外部程序先修改后，MantaSH 后保存可能覆盖其内容；保存失败保留草稿，关闭标签/窗口前可选择保存、放弃或继续编辑。发生替换失败时可能留下 `.mantash-recovery-<uuid>` 文件，先核对其内容再处理，不要批量清理。更多文件完整性约束见[数据文档](data.md#编码在线保存与文件权限)。

## 命令历史

SSH 标签通过终端工具栏或 `Cmd/Ctrl+2` 打开共享历史；本地终端页面没有历史入口。搜索后点击行或按 Enter 只填入当前终端，行内“执行”才会提交命令；前台程序、密码提示和断线时仅允许复制。单击/Shift/Cmd 或 Ctrl 可选择多条记录；过滤隐藏项不参与批量删除，删除前确认固定记录。Esc 在有选中行时清空选择，否则关闭弹窗。

只有 Shell 主动报告的命令会记录，不抓取按键或密码输入。当前接入 zsh、bash 和 PowerShell/PSReadLine；空格前缀、Shell 自定义禁用的集成可能不收录，最多保留 5,000 条。用户主动写入命令行的敏感参数仍可能进入历史，应自行谨慎处理。

## Linux 系统信息

仅 Linux SSH 主机提供系统概览。右栏显示 CPU、内存/Swap、磁盘和网络；CPU/磁盘可展开详情，内存卡打开进程列表，网络卡打开端口列表。进程/端口列表支持搜索、排序和查看详情，后台有效采样会更新结果；缺少 `ss`、权限不足、采样失败或断线会显示原因或旧数据标记，不把未知数据当作零。

进程列表的“命令”列显示采样到的可执行程序及参数，长命令可悬停查看全文。筛选仅对同一命令文本进行不区分大小写的关键词包含匹配，不额外匹配 PID 或用户名；清空关键词显示全部进程，无匹配时显示空结果提示。

进程详情直接平铺完整命令与补充状态，无需展开；可复制 PID 与完整命令。补充状态省略摘要中已有的状态、PID、父 PID 和常驻内存。后台刷新保留当前内容，收到最新数据后直接更新，不显示“正在读取”。“结束”（SIGTERM）与“强制结束”（SIGKILL）分别确认主机、PID、进程身份与影响；连接或进程身份改变、采样过期时操作禁用。发送信号不等于进程已退出，最多等待 10 秒的有效采样确认，不自动升级信号或重试。端口详情保留服务器原始 IPv4/IPv6、状态及进程信息；复制端点或查看关联进程不关闭服务器端口。

系统概览打开期间周期采样；隐藏、断线或切换会话后的旧结果不能更新当前会话。CPU 和网络速率需要两次有效采样，首次不显示猜测值。

## 记忆、窗口与快捷键

连接资料、外观偏好、工具宽度与工作区存于 MantaSH 数据目录；标签和布局自动保存。拖动 SSH 右栏分隔线可调宽度；聚焦分隔线后方向键每次调整 8px，Shift+方向键每次 32px，Home/End 到达边界，双击恢复默认 280px，显示上限为窗口宽度的 50%。重启时本地会话创建新 Shell，SSH 等待手动连接，编辑草稿不恢复。数据异常时原数据库不会被清空，处理方法见[排障](troubleshooting.md)；路径和格式见[数据文档](data.md)。

macOS 使用系统“窗口”菜单管理缩放、平铺和全屏，`Cmd+Shift+0` 打开同一菜单；具体选项取决于系统版本。Windows 使用原生系统标题栏，右上角三个按钮分别为最小化、最大化/还原、关闭；最大化与全屏是不同操作。标题栏拖动、双击和系统窗口菜单由 Windows 处理。关闭时仍检查未保存文件和正在进行的传输。应用内尺寸和全屏操作界面继续保留；Windows 实机行为仍待验收。

| 操作 | macOS | Windows |
|---|---|---|
| 新建本地 / SSH | Cmd+T / Cmd+N | Ctrl+Shift+T / Ctrl+Shift+N |
| 打开连接库 | Cmd+Shift+O | Ctrl+Shift+O |
| 关闭当前文件或标签 | Cmd+W | Ctrl+Shift+W |
| 左右 / 上下分屏 | Cmd+D / Cmd+Shift+D | Ctrl+Shift+D / Ctrl+Alt+D |
| 保存文件 | Cmd+S | Ctrl+S（编辑器）或 Ctrl+Shift+S |
| 设置 | Cmd+, | Ctrl+Shift+, |
| 文件 / 历史 / 系统 | Cmd+1/2/3 | Ctrl+Shift+1/2/3 |
| 切换窗格 | Ctrl+Tab | Ctrl+Tab |
| 终端复制 / 粘贴 / 全选 | Cmd+C/V/A | Ctrl+Shift+C/V/A |
| 关闭弹窗或清空当前选择 | Esc | Esc |

输入法、系统快捷键与 Windows 平台行为以相应平台的实际验收为准。更完整的交互尺寸与视觉规范见[设计文档](design.md)。
