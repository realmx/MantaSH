# MantaSH 视觉与交互规范

唯一视觉基准为已确认的并页设计，本文件描述当前原生实现。平台实机状态见[验收记录](acceptance.md)，实现模块与 QA 入口见[开发验证](development.md)。

## 工作台与标签

顶部标签栏默认 38px，工具栏默认 36px，两行合计约 74px，随实际字体行高增长。顶栏左侧只显示应用图标，无名称字标，释放的宽度归标签区；平台窗口控制保留原生行为，正式程序没有原型外层控制条。

标签区只占应用图标与右侧固定按钮（新建、连接库、设置）之间的可用宽度：标签过多时在此范围内横向滚动，支持触控板横滑与鼠标滚轮，不因数量增加而压缩，溢出内容裁剪在标签区内；固定按钮不参与滚动。设置按钮与窗口右缘（Windows 为原生窗口按钮区）间保留 12px。新建、切换、窗口或字体变化时使活动标签可见，已可见的动态名称变长时补充滚动；用户主动滚开后不被终端输出或标题事件拉回。

标签状态：普通为透明背景与辅助文字色；选中时整枚使用中性底色、正文色和 2px 强调底线（左右各内缩 10px）；悬浮未选中时整枚使用更轻底色。SSH 标签在图标左侧显示固定占位的状态圆点——已连接绿色、连接/验证中蓝色、断开或失败红色；本地标签无圆点。关闭图标使用辅助色，指针进入其自身区域时出现小型中性底色，点击区域随字号适配。所有状态保持相同标签尺寸与字重，不使用阴影；键盘焦点单独显示清晰轮廓；悬浮过渡 120ms，并响应减少动态效果设置。

布局形态：本地终端全宽，无右侧工具、展开按钮或历史弹窗入口；本地历史独立存储。SSH 为上下分区——终端在上，文件面板在下（可拖动调高，头部含标题和关闭按钮）；右侧工具面板只显示系统概览，在线编辑与命令历史均使用弹窗。两个面板在连接建立前不显示，连接成功后自动打开，断开后随监控状态清空一起关闭；工具栏按钮可手动开合。SSH 终端工具栏最左侧是按连接状态变化的断开/取消/重连按钮，其后为地址标识；编码入口使用图标按钮，编码按会话设置并随工作区恢复，不存入连接资料。断线与等待重连不显示状态条，保留上一次终端输出直到新连接成功。连接库按需打开，无常驻左侧栏。

顶部标签的拖动手势仅在当前标签栏内水平排序，不使用自由漂浮的拖拽预览或拖出新窗口。拖动中显示插入线，松开后提交顺序，保留当前活动会话及其内容；竖向拖动、栏外释放、Esc 和窗口失焦不提交重排。macOS 在系统拖动区域中排除标签、按钮和图标，应用交互仍走原 GPUIView；标题栏空白保留系统窗口拖动，不整体禁用窗口移动。Windows 使用透明 GPUI 标题栏，LOGO 只绘制一次；顶栏空白映射为原生 `HTCAPTION`，系统最小化、最大化/还原和关闭按钮通过 Win32 命中测试保留，标签、按钮和弹窗不被拖动命中区抢占。标签区两端支持拖动滚动，普通滚轮仍用于水平浏览。

## 弹窗

所有原生弹窗共用覆盖程序画面全尺寸的遮罩层，弹窗外框在其内水平和垂直居中；窗口尺寸变化后按新视口重新居中，内容超出时在正文列表内滚动而非把弹窗挤到角落。宽度上限：`Modal::is_confirmation()` 分类中的确认弹窗 480px，其它普通弹窗 640px（原本更窄的表单不被放大），在线文本编辑器保留 960px；均继续受视口宽度约束。

## 连接库

连接库默认宽 640px、使用全宽列表，弹窗高度 320–600px（更矮视口按可用高度限制），工具栏、列表和底栏各留 12px。搜索位于顶部，导入导出位于固定底栏；底栏最右侧提供带添加图标的“添加”入口，批量删除与取消选择靠左、仅在有选中行时显示，顶部工具栏不再提供“添加 SSH 连接”按钮。位置指示条贴弹窗内右边界，支持拖动和点击跳转且不遮挡行内操作按钮。

列表每行右侧提供编辑、克隆和连接 3 个 20px 图标按钮，按 UUID 复核资料并阻断行级选择；连接始终打开新标签页，同一资料可开多个独立会话。列表支持排序、多选、范围选择和批量删除；单击单选并更新范围锚点，Shift+单击选择可见顺序中的连续区间，Cmd/Ctrl+单击增减项目；搜索过滤后隐藏行不保留为删除目标。列表行显式 `w_full`。

连接表单默认宽 560px，正文左右各 16px：名称独占一行，主机/端口同行，用户名/密码同行且用户名在左；认证固定为密码方式，不设置终端编码（编码在 SSH 会话中独立选择）。编码选择弹窗固定宽 320px，选项为换行排列的小按钮，点击直接生效，标题栏提供关闭按钮，不显示底部操作条。表单标题与底部操作固定，弹窗随内容自然收缩，超高正文独立滚动。上下文明确的操作使用“新建”“编辑”“克隆”“保存”“返回”，返回按钮保留完整目的地提示；克隆先填写再保存，独立 UUID 不继承凭据。

参考 [iTerm2 Open Quickly](https://iterm2.com/documentation-menu-items.html) 的搜索和会话切换入口，以及 [Termius 的主机连接流程](https://termius.com/) 对已保存目标的直接连接方式。这些只作为交互参考，功能和并页布局仍按本项目规格实现。

## 文件面板与传输

文件导航与文件操作只放在底部文件面板，不在右侧工具面板或终端工具栏重复提供。面板内保留当前路径、上级、刷新、隐藏文件、新建目录、上传文件、传输记录和选中项删除；单击选择，双击文件夹进入、双击文本打开编辑。终端可靠报告目录变化时文件栏自动同步；手动同步、目录上传和文件读取编码选择目前没有可见入口，不作为已提供的操作描述。文件刷新只在原刷新位置显示 loading，不插入“正在读取”行，也不移动文件列表。

文件列表移除表头与行内复选框，使用整行选中底色，悬浮不能覆盖选中反馈。单击单选；Shift+单击选择可见顺序中的连续区间，反复 Shift 选择沿用原起点；Cmd/Ctrl+单击增减项目。双击文件夹进入目录，双击文本进入编辑，带选择修饰键的双击只处理选区。成功导航/刷新重置起点，隐藏或移除的路径不能继续参与批量操作。列表提供键盘全选、清空、方向选择和打开入口。

上传/下载保留文件面板入口与系统文件选择器，进入同一 480px 上限的传输工作弹窗。弹窗依次呈现核对、传输中、结果三种阶段：标题和 footer 固定，仅任务列表纵向滚动。核对行按“方向状态槽（24px）/文件名和来源、目标完整路径/大小（未知显示—）”排列，源和目标分行、长中文或无分隔符名称在列内换行，行间以直线分隔；两种方向使用相同排版，下载不提前伪造文件大小。开始前可移除单项并选择是否覆盖；开始后行内显示排队、真实进度/已传字节、完成或错误，已知总量绘制环形比例，未知总量使用 Spinner，明确不显示虚假百分比。运行阶段的关闭 X、Esc 和“后台继续”只关闭界面；“停止未完成”另行确认固定主机与任务，已完成文件保留。全部成功自动关闭并在原会话原列表请求仍有效时刷新；失败或取消留在结果页显示原因、逐项重试，重试生成新 UUID 并重新核对目标和覆盖选项。传输记录仍可查看后台任务，单批最多两个并发 worker；不增加目录上传入口或更改 SFTP 后端。

## 系统工具

系统面板只保留概览：CPU 模块之上不渲染刷新按钮、错误行或离线提示；连接成功后自动采样，面板可见期间每 3 秒刷新，断开后清空 CPU/内存/交换内存/磁盘/网络。进程和端口从概览卡片打开弹窗——内存/交换内存卡打开“进程”，网络卡打开“端口”；弹窗提供搜索和排序（进程），随后台采样动态更新，不显示手动刷新按钮或更新时间模块。

概览从 CPU 模块开始，模块通栏排列、无外边距和圆角，以全宽 1px 直线分隔，模块内部保留 12px 水平、8px 垂直留白。CPU 和磁盘是可打开详情的资源入口：CPU 显示核心数，磁盘显示已用/总量，轨道按实际内容宽度铺满，名称、核心数/容量和百分比位于轨道上方；窄面板或大字号时文本允许换行，不压缩字体或截断数值。内存与 Swap 合并显示各自已用/总量和百分比，点击该卡片打开进程弹窗。网络保持紧凑统计和 56px 趋势图：双列下载/上传速度，蓝色接收线带浅填充，绿色发送线使用虚线，接口累计量按内容自适应三列。未知百分比显示“—”，未启用 Swap 不伪造用量。

CPU 和磁盘详情弹窗提供总体/核心、全部挂载及文件系统/容量，宽度 480px 并受窗口边界限制。详情绑定当前会话并随最新概览样本刷新；标题栏只有标题与关闭按钮，正文左右各 12px，内容独立滚动，没有主机/采样时间栏或底部操作栏。CPU 核心为无标题紧凑行：名称居左、用量条居中拉伸、百分比居右；多核按两列摆放，单核占整行。磁盘行显示挂载点、设备、占用率、已用/总量、可用量和细用量条，项目以细线分隔。短内容自然收缩，长内容可用滚轮及 Home/End、PageUp/PageDown 浏览；滚动条提供语义中性色反馈，不遮盖数值。

进程列表弹窗标题为“进程”（与单进程“进程详情”区分），640px 目标宽。筛选输入框独占工具行，匹配数量在其下方显示；PID、名称、用户、CPU、内存的排序按钮直接作为固定表头，状态列只读，行内数据与表头同列对齐并单行展示；行末 20px 箭头进入单进程详情，不在列表发送信号。三行等少量进程时弹窗随原始采样数量收紧，筛选时外框不跳变，大量进程时最多 560px 高且仅表体滚动。后台采样持续替换有效列表，错误与无结果明确区分。进程详情使用固定标题栏、独立滚动正文及固定操作底栏（640px 目标宽），正文按固定进程名/PID、操作或读取状态、CPU/常驻内存、用户/状态/父 PID/启动时间、完整命令、原始状态排列，以细线划分信息层次，不叠放卡片。仅身份一致的新 Linux 样本更新指标；CPU 可超过 100%，内存无进程专属总量，均显示原值而不绘制误导性比例条。长命令默认限高预览，可展开/收起且始终复制全文；原始 `/proc/status` 默认收起，展开后在限高区域内滚动。普通“结束”和危险色“强制结束”并列，失效/断线/采样错误/待确认时禁用并给出原因；两者均确认固定主机、PID、名称和动作，取消回到原详情并保留展开状态。发送信号和确认退出分别反馈，失败/身份变化/结果未知不被当作成功、不自动重试或升级；关闭回原列表保留查询、排序与位置。预览不发送真实信号。

端口列表弹窗标题为“端口”，640px 目标宽、最多 560px 高并随视口缩小；少量结果按原始采样条数收紧，筛选时外框不跳变，展开行内原文时增加阅读空间。搜索独占工具行，“全部 / TCP / UDP”筛选与结果状态同处下一行；端口列头点击切换数值升/降序，协议/状态列头点击按协议排序，绑定地址与进程列只读，表头和单行记录保持精确对齐。端口号为主要扫描点，长地址和进程名截断；每行末尾 20px 箭头展开完整原始本地端点、对端、协议/状态和进程，并保留复制端点、复制数字端口两个本机动作；从 `ss` 原始字段解析出的 PID 会在展开区列出当前采样中的关联进程，点击箭头进入现有进程详情查看完整命令和原始状态。只有结果行滚动，工具栏和列头固定；失败采样、真实空结果和断线明确区分，不伪造数据，UDP 状态按 `ss` 原样显示，重复记录不合并。沿用语义色与原生按钮包装层，不增加卡片、远端操作或新的系统侧栏页。

进程与端口列表的表体右缘使用常显中性色位置指示条：只在内容超出视口时出现，支持拖动和点击轨道跳转，不遮挡行内操作，也不改变工具栏和列头布局，且不随行内容上下移动。

## 共享 SSH 历史

历史按本地和全部 SSH 两份列表组织，SSH 标签共用查询、多选选区与列表滚动。弹窗宽度固定 640px，按内容自适应高度，范围为 320px–600px（受可用视口高度限制）并始终居中浮在应用页面上；工具栏与列表保持 8px 间距，列表底部与 footer 之间保留 12px 间距，列表内容滚动不改变 footer 位置，滚动条贴近列表右边界并随滚动偏移同步位置。

弹窗不提供管理按钮、管理模式和全选/取消全选；选择与连接库一致：单击单选、Shift 连选、Cmd/Ctrl 增减，过滤隐藏的记录不能成为删除目标。footer 仅在选中行时显示数量、“删除”和“取消选择”；取消只清空选区，删除按当前可见的固定记录 UUID 确认后执行。Esc 在有选中行时先清空，否则关闭弹窗；header X 始终可关闭。命令文本换行，复制和执行图标在右侧；同一命令仅保留最新一条。执行只在可靠 Shell 提示符下直接提交，不弹二次确认。

## 排版与组件

界面 14px，终端/编辑器 12px，均为客户区逻辑像素。UI 使用平台系统无衬线字体，终端默认 Menlo/macOS 或 Consolas/Windows，独立选择系统已安装字体。终端行高以字号的 1.5 倍与实际字形高度较大者计算；字体改变后重新测量和调整 PTY 网格，不重建会话。

字号每次 1px；界面与终端范围均为 12–18px，加载和设置时钳制越界值。按钮与单行输入框统一 24px 默认档，随行高缩放且不超过 32px；小圆角 5px，弹层 10px，统一 Lucide 图标；需要空间时换行或滚动，不裁掉主要动作。所有操作提供键盘焦点；所有可点击按钮悬停显示手型光标，禁用显示禁止光标，由统一按钮包装层保证。

间距固定阶梯为 4 / 8 / 12 / 16 / 24 / 32 / 40 / 48px（细节 / 操作 / 面板 / 分节 / 大 / 特大 / 超大 / 最大），使用 `theme::SPACE_*` 常量，禁止硬编码阶梯外的间距值。按钮大小阶梯：小图标钮 20px、标准钮 24px、高度上限 32px；单行输入框统一 24px 档（编辑器正文除外）；弹窗 header 按钮统一 24px 方形；行内图标钮 20px 方形。字体维持用户设置，控件按实际字号适配。刷新、复制等重复操作使用带提示和焦点样式的图标。

## 尺寸、分屏与焦点

验收 960×640、1280×800、1440×900。SSH 右栏无偏好时默认按 280px 最小宽度显示，分隔线 6px，且不超过窗口客户区的 50%；小窗口以上限优先。只保存主动设置的偏好宽度，用户拖动后的值在收起、展开和重启后恢复，临时窗口限制不回写偏好。支持拖动、方向键、Home/End、双击恢复默认。工具页按会话保存；收起/展开恢复最后页面。

仅本地支持最多 5 个窗格，以布局树表达上下、左右及混合方向。每个叶子有独立 Shell、目录、编码和焦点。空间不足时工作区内部滚动。关闭叶子折叠对应分支；关闭最后标签保留空工作台和新建入口。标签和比例变化不改写其他会话标识。

本地标题根据可靠报告的目录或程序显示，跟随该标签聚焦的窗格。SSH 标题使用连接名称，缺失时使用地址；非默认端口保留。目录和程序只进入 SSH 悬停提示。后台输出、传输和采样不改变当前焦点。

终端的 Tab/Shift+Tab 使用终端输入语义，由 Shell 或前台程序处理，不能触发界面焦点导航；表单里的同名键保留控件导航，Ctrl+Tab 保留本地窗格切换。输入法组合期间保护未提交文本，不将 Tab 写入 PTY。窗口 Zoom、还原和连续尺寸变化保持 PTY 端点与终端网格同步；网格尺寸未追上测量尺寸时不复用旧帧并清空 retained canvas，Shell 提示符不会因旧列数重绘或旧字形残留而散落。

本地终端接收标准 `clear` 的清历史加清屏组合后，后续窗口放大不得从 scrollback 回填已清除的旧提示符；不清历史的屏幕擦除和普通历史滚动不受影响。未清屏的本地空闲提示符缩放时，行尾右提示符的 reflow 不能制造可回填的重复提示符行——仅可丢弃原本无历史、无输入、首行提示符且其它屏幕行全空时由 resize 新生成的历史；用户正在编辑的长命令、真实输出和已有 scrollback 必须保留。

## 窗口操作菜单

macOS 使用 AppKit 标准「窗口」菜单，常用平铺、居中、填满、全屏与还原由系统提供。Cmd+Shift+0 打开同一菜单，顶栏不显示自定义窗口操作按钮；具体选项由 macOS 和当前窗口尺寸决定。Windows 使用透明 GPUI 标题栏，LOGO 不与原生标题栏重复；右侧最小化、最大化/还原、关闭和顶栏空白拖动均通过 Win32 原生命中测试工作。Windows 实机验收仍未验证，其它平台保留现有备用实现。

## 品牌资源

正式名称与字标统一为 **MantaSH**（M、S、H 大写，不附加句点）。窗口标题、菜单、品牌展示和文档使用同一写法。程序、包名、文件路径和环境变量属于技术标识，遵循各自的命名规范。

标识为“共享透镜”抽象构成：两个交叠的圆——左上实心圆（品牌蓝 `#1F7FA6`）与右下空心圆（白色描边，描边宽约网格 4.4 单位）——在中央共享一枚透镜，隐喻本地与远端、终端与文件面板的一次连接。主应用图标为深蓝 `#142A45` 圆角底；原生工具栏使用随主题着色的单色版本（[mark SVG](../assets/mantash-mark.svg) 为品牌蓝双圆）。

源文件为 [彩色 SVG](../assets/mantash.svg)、[单色 SVG](../assets/mantash-monochrome.svg)、[黑色版](../assets/mantash-black.svg) 和 [白色版](../assets/mantash-white.svg)。交付 PNG 16/32/64/128/256/512/1024、[ICO](../assets/mantash.ico) 与 [ICNS](../assets/mantash.icns)。图形具有独立轮廓，小尺寸不依赖细线或文字识别。

`scripts/generate_logo.py` 按同一 64 单位几何生成全部矢量、位图和 [品牌展示 PNG](../assets/logo-preview.png)／[PDF](../assets/logo-preview.pdf)，设计依据为 [折流](brand-philosophy.md)。展示板使用随项目提供的 Instrument Sans 和 Work Sans（OFL）；应用文字仍尊重用户选择的界面字体。使用 Python 3.10 或更新版本，复现命令为 `python3 -m pip install -r requirements-tools.txt` 后运行 `python3 scripts/generate_logo.py`。生成资源不代表已完成应用打包、签名或发布；实际窗口截图与输入法/平台待验项见 [原生验收](acceptance.md)。
