# MantaSH 视觉与交互规范

本文件描述当前原生并页布局、控件和视觉规则。功能操作见[用户手册](user-guide.md)，异步交互与服务边界见[架构](architecture.md)，持久化契约见[数据文档](data.md)。平台证据见[验收记录](acceptance.md)，复现入口见[开发与验证](development.md)。

## 工作台与标签

顶部标签栏默认 38px，工具栏默认 36px，两行合计约 74px，随实际字体行高增长。顶栏左侧只显示应用图标，无名称字标，释放的宽度归标签区；平台窗口控制保留原生行为。

标签区只占应用图标与右侧固定按钮（新建、连接库、设置）之间的可用宽度：标签过多时在此范围内横向滚动，支持触控板横滑与鼠标滚轮，不因数量增加而压缩，溢出内容裁剪在标签区内；固定按钮不参与滚动。设置按钮与窗口右缘（Windows 为原生窗口按钮区）间保留 12px。新建、切换、窗口或字体变化时使活动标签可见，已可见的动态名称变长时补充滚动；用户主动滚开后不被终端输出或标题事件拉回。

标签状态：普通为透明背景与辅助文字色；选中时整枚使用中性底色、正文色和 2px 强调底线（左右各内缩 10px）；悬浮未选中时整枚使用更轻底色。SSH 标签在图标左侧显示固定占位的状态圆点——已连接绿色、连接/验证中蓝色、断开或失败红色；本地标签无圆点。关闭图标使用辅助色，指针进入其自身区域时出现小型中性底色，点击区域随字号适配。所有状态保持相同标签尺寸与字重，不使用阴影；键盘焦点单独显示清晰轮廓；悬浮过渡 120ms，并响应减少动态效果设置。

布局形态：本地终端全宽，无右侧工具、展开按钮或历史弹窗入口；本地历史独立存储。SSH 为上终端、下文件、右系统概览；在线编辑与历史使用弹窗。文件面板在连接成功时按“连接后展开文件面板”偏好打开，系统概览自动打开；断线关闭面板并清空监控，保留旧终端输出直到新连接成功。工具栏最左为闪电连接按钮，按当前状态执行断开、取消或重连，其后为地址与会话编码，编码随工作区恢复而不写入连接资料。连接库按需打开，无常驻左栏。

顶部标签的拖动手势仅在当前标签栏内水平排序，不使用自由漂浮的拖拽预览或拖出新窗口。拖动中显示插入线，松开后提交顺序，保留当前活动会话及其内容；竖向拖动、栏外释放、Esc 和窗口失焦不提交重排。macOS 在系统拖动区域中排除标签、按钮和图标，应用交互仍走原 GPUIView；标题栏空白保留系统窗口拖动，不整体禁用窗口移动。Windows 使用透明 GPUI 标题栏，LOGO 只绘制一次；顶栏空白映射为原生 `HTCAPTION`，系统最小化、最大化/还原和关闭按钮通过 Win32 命中测试保留，标签、按钮和弹窗不被拖动命中区抢占。标签区两端支持拖动滚动，普通滚轮仍用于水平浏览。

## 弹窗

所有弹窗共用居中遮罩及“标题 → 单一正文 → 可选底栏”，视口左右至少留 16px、上下至少留 24px。标题、正文、底栏共用 12px 水平边线；没有操作时不渲染空底栏。X/Esc 按弹窗语义取消或收起，底栏不重复关闭；取消紧邻主操作之前。普通子弹窗恢复原父帧的焦点与滚动，危险确认绑定固定目标。

弹窗宽度按内容结构设置，以下及后文宽度均为 14px 默认界面字号的基准值；12–14px 保持基准宽度，15–18px 每增加 1px 字号加宽 16px，最终受视口边距限制。编辑器使用独立文档字号，宽度上限保持 960px，高度取扣除上下边距后可用视口的 85%。采样更新、筛选与长路径不改变目标宽度，避免弹窗跳动；正文允许换行或滚动。

| 内容 | 基准宽度 |
|---|---|
| 编码选择 | 320px |
| 关于、密码输入、重命名/新建目录 | 360px |
| 字体选择、保存冲突、文档/编辑器未保存确认 | 440px |
| 删除、导入、链接跳转、关闭会话/窗口、传输及停止、进程结束确认；资源详情与窗口设置 | 480px |
| 应用设置、更新说明 | 520px |
| SSH 连接表单、主机指纹确认 | 560px |
| 连接库、命令历史、进程/端口列表、进程详情、传输记录 | 640px |
| 在线编辑器 | 960px |

## 连接库

连接库默认宽 640px，高度 320–600px 并受视口限制，工具栏、列表和底栏各留 12px。顶部为搜索、按名称排序、导入、添加；底栏保留整库导出和选区删除/取消选择。排序后持久化资料顺序，手动拖动排序继续可用。位置指示条贴列表右缘，支持拖动与跳转，不遮挡行内动作。

列表每行右侧提供编辑、克隆和连接 3 个 20px 图标按钮，按 UUID 复核资料并阻断行级选择；连接始终打开新标签页，同一资料可开多个独立会话。列表支持排序、多选、范围选择和批量删除；单击单选并更新范围锚点，Shift+单击选择可见顺序中的连续区间，Cmd/Ctrl+单击增减项目；搜索过滤后隐藏行不保留为删除目标。列表行显式 `w_full`。

连接表单宽 560px，正文水平 12px：名称独占一行，主机/端口同行，用户/密码同行；密码框右侧为 20px 的 Lucide `eye`/`eye-off` 无边框图标按钮（统一按钮封装，提示“显示密码/隐藏密码”），每次打开表单默认遮蔽、不预读凭据；编辑已有资料且密码框为空、密码记忆开启时，首次点击在后台读取已保存密码并明文填入，无保存值时保持空框并以占位提示“未保存密码”，读取失败保持遮蔽并在表单内显示错误；再次点击重新遮蔽但保留内容；新建资料的用户默认填入 `root`，端口固定预填 `22`，可按连接单独修改，仅密码认证。设置不提供全局端口选项，编辑或克隆资料保留原端口。底栏右侧依次为取消、仅保存、保存并连接。编码在会话或编辑工具栏选择，320px 弹窗点击即生效、无底栏。克隆生成独立 UUID，不复制密码；编辑表单只在点击眼睛时按需读取凭据。

参考 [iTerm2 Open Quickly](https://iterm2.com/documentation-menu-items.html) 的搜索和会话切换入口，以及 [Termius 的主机连接流程](https://termius.com/) 对已保存目标的直接连接方式。这些只作为交互参考，功能和并页布局仍按本项目规格实现。

## 文件面板与传输

文件导航与文件操作只放在底部文件面板，不在右侧工具面板或终端工具栏重复提供。面板内保留当前路径、上级、刷新、隐藏文件、新建目录、上传文件、传输记录和选中项删除；单击选择，双击文件夹进入、双击文本打开编辑。终端可靠报告目录变化时文件栏自动同步；手动同步、目录上传和文件读取编码选择目前没有可见入口，不作为已提供的操作描述。文件刷新只在原刷新位置显示 loading，不插入“正在读取”行，也不移动文件列表。

文件列表保留与行同列对齐、随内容横向滚动的固定表头，移除行内复选框，使用整行选中底色，悬浮不能覆盖选中反馈。单击单选；Shift+单击选择可见顺序中的连续区间，反复 Shift 选择沿用原起点；Cmd/Ctrl+单击增减项目。双击文件夹进入目录，双击文本进入编辑，带选择修饰键的双击只处理选区。成功导航/刷新重置起点，隐藏或移除的路径不能继续参与批量操作。列表提供键盘全选、清空、方向选择和打开入口。

文件列表依次显示名称、右对齐大小、左对齐修改时间、操作四列；“大小”“修改时间”表头是统一包装层的无边框透明按钮（手型光标、悬停提示），点击按降序 → 升序 → 默认顺序循环，当前排序列使用选中底色并在标签前显示 Lucide `arrow-down` / `arrow-up`，未排序时保留同尺寸空位使标签不移动；操作列提供重命名/复制/下载/删除四个直接按钮。默认动作列 92px（4×20px 按钮＋3×4px 间距）。修改时间使用辅助文字色、单行不换行，列宽用当前界面字体的实际字形宽度测量 `0000-00-00 00:00:00`（`YYYY-MM-DD HH:mm:ss`，每个数字位取最宽数字）与表头文字加排序箭头位（图标、8px 间距和按钮边框），取较宽者再加 4px（`theme::SPACE_SMALL`）余量；大小列同样保证表头文字加箭头位不被裁切，字形不可用时才按偏宽的校准字宽估算；列宽贴合文字、不提供拖动调整；大小列拖动边缘到修改时间列、修改时间列到首按钮的间距相同，按面板宽度使用 8px 或 12px。名称列默认占用其余宽度（最小 140px），大字号扩展列宽或内容横滚，不截断时间、不隐藏动作。按钮绑定 Owner、目录请求和路径，不触发行选择；同连接内导航保留复制来源，重连/关闭清除。

编辑器工具栏显示路径、编码、基础格式化，正文复用真实行号并占剩余高度。X/Esc 收起视图并保留草稿，放弃独立确认，保存失败不清草稿。格式化只整理换行与行末空白，单次可撤销，不自动保存；结果按 Owner、文档和 revision 复核。

上传/下载使用同一 480px 传输弹窗，依次为核对、运行、结果；标题与底栏固定，任务列表单独滚动。核对仅显示方向、文件名、大小和移除按钮，不展示完整路径；运行和记录页保留路径与错误提示。未知大小与百分比不伪造；全应用共用最多两个并发 worker。X/Esc/后台继续只收起视图，停止另行确认固定任务；全部成功可关闭并仅刷新仍有效的原目录，失败或取消保留结果，重试创建新 UUID。结果页不重复关闭按钮。

## 系统工具

系统面板只保留概览：CPU 模块之上不渲染刷新按钮、错误行或离线提示；连接成功后自动采样，面板可见期间每 3 秒刷新，断开后清空 CPU/内存/交换内存/磁盘/网络。进程和端口从概览卡片打开弹窗——内存/交换内存卡打开“进程”，网络卡打开“端口”；弹窗提供搜索和排序（进程），随后台采样动态更新，不显示手动刷新按钮或更新时间模块。

概览从 CPU 模块开始，模块通栏排列、无外边距和圆角，以全宽 1px 直线分隔，模块内部保留 12px 水平、8px 垂直留白。CPU 和磁盘是可打开详情的资源入口：CPU 显示核心数，磁盘显示已用/总量，轨道按实际内容宽度铺满，名称、核心数/容量和百分比位于轨道上方；窄面板或大字号时文本允许换行，不压缩字体或截断数值。内存与 Swap 合并显示各自已用/总量和百分比，点击该卡片打开进程弹窗。网络保持紧凑统计和 56px 趋势图：双列下载/上传速度，蓝色接收线带浅填充，绿色发送线使用虚线，接口累计量按内容自适应三列。未知百分比显示“—”，未启用 Swap 不伪造用量。

CPU 和磁盘详情弹窗提供总体/核心、全部挂载及文件系统/容量，宽度 480px 并受窗口边界限制。详情绑定当前会话并随最新概览样本刷新；标题栏只有标题与关闭按钮，正文左右各 12px，内容独立滚动，没有主机/采样时间栏或底部操作栏。CPU 核心为无标题紧凑行：名称居左、用量条居中拉伸、百分比居右；多核按两列摆放，单核占整行。磁盘行显示挂载点、设备、占用率、已用/总量、可用量和细用量条，项目以细线分隔。短内容自然收缩，长内容可用滚轮及 Home/End、PageUp/PageDown 浏览；滚动条提供语义中性色反馈，不遮盖数值。

进程列表弹窗标题为“进程”（与单进程“进程详情”区分），640px 目标宽。筛选输入框独占工具行，仅对“命令”列同源的可执行程序及参数作不区分大小写的包含匹配，匹配数量在其下方显示；数据列为 PID、命令、用户、CPU、内存，排序按钮直接作为固定表头，行内数据与表头同列对齐并单行展示，长命令悬停显示全文；行末 20px 箭头进入单进程详情，状态在详情中查看。三行等少量进程时弹窗随原始采样数量收紧，筛选时外框不跳变，大量进程时最多 560px 高且仅表体滚动。后台采样持续替换有效列表，错误与无结果明确区分。

进程详情使用固定标题栏、独立滚动正文及固定操作底栏（640px 目标宽）。摘要按双列组织为 PID/状态、CPU/常驻内存、用户/父 PID，启动时间占完整一行；标签与值同行，PID 可复制，PID 和资源数值加粗。移除摘要内重复的小节标题与整块背景内边距，行间距 8px、列间距 16px、正文分组间距 12px；操作结果和读取错误紧随身份区。标签使用次要文字色且不挤缩，内容保持正常字号并允许换行，沿用明暗主题语义色，不叠放卡片。完整命令与补充状态保留标题及分隔线，分隔线上方 12px、下方 8px，文本区域内边距 8px。仅身份一致的新 Linux 样本更新指标；CPU 可超过 100%，内存无进程专属总量，均显示原值而不绘制误导性比例条。完整命令以等宽字体直接平铺、允许换行且始终复制全文，不重复显示列表中的命令摘要；补充状态直接显示 `/proc/PID/status` 中未在摘要展示的字段，去掉 State、Pid、PPid、VmRSS，保留 Name、Uid、Tgid 等不同含义字段。全部内容随正文统一滚动，不折叠、不另设限高滚动区。普通“结束”和危险色“强制结束”并列，失效/断线/采样错误/待确认时禁用并给出原因；两者均确认固定主机、PID、名称和动作，取消回到原详情并保留滚动位置。发送信号和确认退出分别反馈，失败/身份变化/结果未知不被当作成功、不自动重试或升级；关闭回原列表保留查询、排序与位置。预览不发送真实信号。

进程详情底栏右侧依次排列“取消”“结束”“强制结束”，按钮之间统一 8px，无嵌套按钮组或弹性占位。

进程详情打开时立即请求最新监控采样，保持打开时按所属会话每 3 秒继续采样，不依赖侧栏当前页；有效新采样到达后复核进程身份并刷新完整命令和原始状态，同一详情请求未完成时不叠加请求。刷新保留已有文本和滚动位置，不显示“正在读取”；最新有效数据到达后直接更新，失败明确提示而不伪造新数据。结束确认期间暂停详情的周期采样，关闭详情后不再由它发起采样；系统概览自身的采样仍按可见状态运行。PID 与状态各占半宽，标签不收缩、值使用剩余列宽并允许换行，避免中文标签被挤成竖排。

端口列表弹窗标题为“端口”，640px 目标宽、最多 560px 高并随视口缩小；少量结果按原始采样条数收紧，筛选时外框不跳变，展开行内原文时增加阅读空间。搜索独占工具行，“全部 / TCP / UDP”筛选与结果状态同处下一行；端口列头点击切换数值升/降序，协议/状态列头点击按协议排序，绑定地址与进程列只读，表头和单行记录保持精确对齐。端口号为主要扫描点，长地址和进程名截断；每行末尾 20px 箭头展开完整原始本地端点、对端、协议/状态和进程，并保留复制端点、复制数字端口两个本机动作；从 `ss` 原始字段解析出的 PID 会在展开区列出当前采样中的关联进程，点击箭头进入现有进程详情查看完整命令和补充状态。只有结果行滚动，工具栏和列头固定；失败采样、真实空结果和断线明确区分，不伪造数据，UDP 状态按 `ss` 原样显示，重复记录不合并。沿用语义色与原生按钮包装层，不增加卡片、远端操作或新的系统侧栏页。

端口工具栏四周内边距、搜索框与筛选行间距、“全部 / TCP / UDP”按钮间距及筛选组与结果状态间距统一为 8px。

进程与端口列表的表体右缘使用常显中性色位置指示条：只在内容超出视口时出现，支持拖动和点击轨道跳转，不遮挡行内操作，也不改变工具栏和列头布局，且不随行内容上下移动。

## 共享 SSH 历史

历史按本地和全部 SSH 两份列表组织，SSH 标签共用查询、多选选区与列表滚动。弹窗基准宽度 640px，大字号按公共规则加宽；按内容自适应高度，范围为 320px–600px（受可用视口高度限制）并始终居中浮在应用页面上；工具栏与列表保持 8px 间距，列表底部与 footer 之间保留 12px 间距，列表内容滚动不改变 footer 位置，滚动条贴近列表右边界并随滚动偏移同步位置。

历史仅显示命令及复制/填入/执行，不显示来源和时间。列表内首尾 trim 后精确去重，重复可靠执行复用 UUID 并置顶；复制/填入不改排序。单击、Shift、Cmd/Ctrl 选择记录，隐藏项不参与删除；footer 仅选中时显示删除和取消选择。Esc 先清空选区，再关闭；X 可直接关闭。弹窗实例在打开时固定 Owner 和列表范围，父帧恢复不重新取活动窗格。填入与执行核对该实例、活动 Owner、终端所属连接尝试、取消状态和可靠 Shell 提示符。

颜色由 `src/ui/theme.rs` 的语义 Palette 集中管理。默认采用白天，恢复有效用户设置。普通文字对比度目标至少 4.5:1；错误同时有文字、状态和目标信息。终端 ANSI 基础色分别适配日夜模式，索引色及真彩色由终端引擎解释。

普通操作按钮按动作使用以下五种语义色，由 `ButtonPalette` 集中提供日夜主题的默认、悬停、按下和选中颜色：

| 类型 | 色系 / 用途 | 白天底色 / 文字 | 黑夜底色 / 文字 |
|---|---|---|---|
| `default` | 中性灰；取消、关闭、返回、刷新、复制、编辑、筛选 | `#E9EEF3` / `#24344A` | `#263448` / `#DDE6F0` |
| `primary` | 蓝；添加、创建、应用、导入导出、上传下载、执行、重试 | `#23678C` / `#FFFFFF` | `#82C5EA` / `#111925` |
| `success` | 绿；保存、保存并连接、连接和重连 | `#23754C` / `#FFFFFF` | `#73C69B` / `#111925` |
| `warning` | 橙；结束进程、停止传输、断开或取消连接、重置、丢弃本地修改后重新加载、安装更新并重启 | `#F0B44D` / `#382509` | `#F0B44D` / `#382509` |
| `danger` | 红；删除、丢弃草稿、冲突覆盖、强制结束进程 | `#B33838` / `#FFFFFF` | `#EF9696` / `#111925` |

透明、菜单和标签只是外观，不增加操作色类型。透明图标按钮使用同色系文字，悬停/按下使用浅底；白天警告文字用 `#8A530B` 保持可读性。图标与文字共用操作色，标签和普通关闭保持中性。禁用状态优先于选中，所有操作统一使用中性文字和底色，不保留可操作的彩色反馈。取消尚未提交的表单和从核对列表移除项目使用 `default`；停止已经开始的工作使用 `warning`。颜色辅助文字与图标表达含义，不单独承担风险提示。

SSH 工具栏的连接按钮使用同一枚 Lucide `zap` 闪电图标，按当前连接状态着色：已连接为 `success` 绿色，连接中、认证中、等待指纹确认或密码输入为 `primary` 蓝色，已断开、失败、取消或等待重连为 `danger` 红色。保留透明图标按钮外观与尺寸；悬停提示说明实际动作，依次为断开连接、取消或重新连接。连接库中的连接按钮仍按操作使用 `success`。

用量条颜色由数值决定：0% 端点为绿色，0–25% 在绿与蓝之间连续插值；25–85% 固定蓝色；85–100% 在蓝与红之间连续插值。单条已用部分使用当前比例对应的同一颜色，不铺设整条彩虹渐变。深色主题使用同色系较亮端点，网络仍按收发方向着色。

## 排版与组件

界面 14px，终端/编辑器 12px，均为客户区逻辑像素。UI 使用平台系统无衬线字体，终端默认 Menlo/macOS 或 Consolas/Windows，独立选择系统已安装字体。终端行高以字号的 1.5 倍与实际字形高度较大者计算；字体改变后重新测量和调整 PTY 网格，不重建会话。

字号每次 1px；界面与终端范围均为 12–18px，加载和设置时钳制越界值。按钮与单行输入框统一 24px 默认档，随行高缩放且不超过 32px；小圆角 5px，弹层 10px，统一 Lucide 图标；需要空间时换行或滚动，不裁掉主要动作。所有操作提供键盘焦点；所有可点击按钮悬停显示手型光标，禁用显示禁止光标，由统一按钮包装层保证。

间距固定阶梯为 4 / 8 / 12 / 16 / 24 / 32 / 40 / 48px（细节 / 操作 / 面板 / 分节 / 大 / 特大 / 超大 / 最大），使用 `theme::SPACE_*` 常量，禁止硬编码阶梯外的间距值。按钮大小阶梯：小图标钮 20px、标准钮 24px、高度上限 32px；单行输入框统一 24px 档（编辑器正文除外）；弹窗 header 按钮统一 24px 方形；行内图标钮 20px 方形。字体维持用户设置，控件按实际字号适配。刷新、复制等重复操作使用带提示和焦点样式的图标。

设置按外观、终端、连接与安全三组排列，组间使用与内容列等宽的 1px 横向分割线，颜色取当前主题的边框色。分割线位于后两组标题上方，首组顶部不加线，沿用面板和标题的现有间距。

设置中的主题和语言选项，当前选中项使用 `primary` 实心蓝色选中态，未选中项使用 `default` 中性灰。白天为蓝底白字，黑夜为浅蓝底深色字；悬停时保留选中配色，复用统一按钮的颜色与焦点规则。

设置中的跟随系统外观、鼠标报告、连接后打开文件面板和记住连接密码使用右对齐的 Switch。轨道为 36×20px，点击区域宽 44px、高度随界面字号在 24–32px 内适配；开启使用主题蓝色，关闭使用中性灰，滑块左右位置同时表达状态。焦点显示独立轮廓，Tab/Shift+Tab 切换焦点，空格或 Enter 切换一次，长按不连续切换；悬停提示包含设置名称和当前状态。凭据开关下方不显示独立说明行，行为说明在用户指南中维护。保留原有即时生效与异步保存逻辑，关闭记住密码不删除已保存密码。

### 界面文案

文案集中在 `src/ui/i18n.rs`，中文和英文同步。标题已表达的内容不重复为副标题，界面避免底层实现说明；保留会影响决定的主机指纹、明文密码导出、覆盖/删除、放弃草稿、编码限制及操作失败原因。图标按钮以动作命名，文件行按钮同时标明目标；错误不能只靠颜色表达。

## 尺寸、分屏与焦点

验收 960×640、1280×800、1440×900。SSH 右栏无偏好时默认按 280px 最小宽度显示，分隔线 6px，且不超过窗口客户区的 50%；小窗口以上限优先。只保存主动设置的偏好宽度，用户拖动后的值在收起、展开和重启后恢复，临时窗口限制不回写偏好。支持拖动、方向键、Home/End、双击恢复默认。工具页按会话保存；收起/展开恢复最后页面。

仅本地支持最多 5 个窗格，以布局树表达上下、左右及混合方向。每个叶子有独立 Shell、目录、编码和焦点。空间不足时工作区内部滚动。关闭叶子折叠对应分支；关闭最后标签保留空工作台和新建入口。标签和比例变化不改写其他会话标识。

本地标题根据可靠报告的目录或程序显示，跟随该标签聚焦的窗格。SSH 标题使用连接名称，缺失时使用地址；非默认端口保留。目录和程序只进入 SSH 悬停提示。后台输出、传输和采样不改变当前焦点。

终端的 Tab/Shift+Tab 使用终端输入语义，由 Shell 或前台程序处理，不能触发界面焦点导航；表单里的同名键保留控件导航，Ctrl+Tab 保留本地窗格切换。输入法组合期间保护未提交文本，不将 Tab 写入 PTY。窗口 Zoom、还原和连续尺寸变化保持 PTY 端点与终端网格同步；网格尺寸未追上测量尺寸时不复用旧帧并清空 retained canvas，Shell 提示符不会因旧列数重绘或旧字形残留而散落。

本地终端接收标准 `clear` 的清历史加清屏组合后，后续窗口放大不得从 scrollback 回填已清除的旧提示符；不清历史的屏幕擦除和普通历史滚动不受影响。未清屏的本地空闲提示符缩放时，行尾右提示符的 reflow 不能制造可回填的重复提示符行——仅可丢弃原本无历史、无输入、首行提示符且其它屏幕行全空时由 resize 新生成的历史；用户正在编辑的长命令、真实输出和已有 scrollback 必须保留。

## 窗口操作菜单

macOS 使用 AppKit 标准「窗口」菜单，常用平铺、居中、填满、全屏与还原由系统提供。Cmd+Shift+0 打开同一菜单，顶栏不显示自定义窗口操作按钮；具体选项由 macOS 和当前窗口尺寸决定。Windows 使用透明 GPUI 标题栏，LOGO 不与原生标题栏重复；右侧最小化、最大化/还原、关闭和顶栏空白拖动均通过 Win32 原生命中测试工作。Windows 实机验收仍未验证，其它平台保留现有备用实现。

## 品牌资源

正式名称与字标统一为 **MantaSH**（M、S、H 大写，不附加句点）。窗口标题、菜单、品牌展示和文档使用同一写法。程序、包名、文件路径和环境变量属于技术标识，遵循各自的命名规范。

标识为“折峰”：四片平面折叠成字母 M，依次使用薄荷绿 `#B6F1DE`、青绿 `#58BEBA`、浅冰色 `#D6F6F0` 和淡紫 `#7F91DA`，背景为深蓝 `#101B2A`。主形占标准画布宽度的 55.8%，保持选定方案的居中与留白。原生顶栏和关于窗口使用随主题着色的单色外轮廓，通过收紧视框维持小尺寸识别度。

正式品牌资源只有四个文件：[界面单色 SVG](../assets/mantash-monochrome.svg)、[128px 文档 PNG](../assets/mantash-128.png)、[Windows ICO](../assets/mantash.ico) 与 [macOS ICNS](../assets/mantash.icns)。ICO 内置 16/24/32/48/64/128/256px 表示，ICNS 内置平台多尺寸表示；不另外输出备用色版或预览 PNG。macOS 图标铺满不透明深蓝背景、由系统处理轮廓；Windows ICO 和文档 PNG 使用圆角背景。界面操作图标另由组件库及 `assets/icons/` 提供，命令历史执行按钮使用 `assets/mantash-play.svg`。

![MantaSH](../assets/mantash-128.png)

[generate_logo.py](../scripts/generate_logo.py) 是品牌几何与配色的唯一来源，按同一 64 单位几何生成 SVG、文档 PNG 和平台 ICO/ICNS，设计依据为[折峰](brand-philosophy.md)。透明标识采用 48 单位视框；单色版本使用连续外轮廓，避免色面交界的细缝。生成过程不依赖字体文件，应用文字仍尊重用户选择的界面字体。使用 Python 3.10 或更新版本，复现命令为 `python3 -m pip install -r requirements-tools.txt` 后运行 `python3 scripts/generate_logo.py`；运行 `python3 -m unittest discover -s tests -p test_logo_assets.py` 核对资源一致性。生成资源不代表已完成应用打包、签名或发布；实际窗口截图与输入法/平台待验项见[原生验收](acceptance.md)。
